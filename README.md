## 🛠️ Features

* **Multi-Device Support:** Seamless connection via QR or pairing code logic.
* **Modular Structure:** Clean code separation with custom functions and plugins.
* **Highly Customizable:** Easily configure behaviors using `settings.json`.
* **Media Handling:** Built-in tools for managing and downloading rich media content.
